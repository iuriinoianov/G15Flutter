Game 15 on Flutter

## Game 15

**Game 15** (also known as the 15-puzzle or sliding puzzle) is a classic single-player sliding tile puzzle. It consists of a 4×4 grid containing 15 numbered square tiles and one empty space. The goal is to arrange the tiles in numerical order (1–15) by sliding them one at a time into the blank space.

The puzzle was invented by Noyes Palmer Chapman in the 1870s and popularised by Sam Loyd in the 1880s. Not every initial configuration is solvable — exactly half of all starting positions can be solved.

## Flutter

**Flutter** is Google's open-source UI toolkit for building natively compiled, cross-platform applications from a single codebase. It supports Android, iOS, web, Windows, macOS, and Linux targets.

Flutter uses the **Dart** programming language and provides a rich set of pre-built widgets that follow Material Design and Cupertino (iOS-style) guidelines. The framework's reactive, widget-based architecture enables expressive UIs and fast development cycles via its hot-reload feature.

## About This Project

This project implements the Game 15 sliding puzzle using the Flutter framework, demonstrating how to build an interactive, cross-platform mobile game with a clean Dart/Flutter codebase.
